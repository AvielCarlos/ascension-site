# Contributing to Ascension Technologies

Welcome. We are building Connectome — an open-source AI.OS for human fulfilment. The central brain is Ora.

We are a non-profit, open-source DAO. Contributions are volunteer-based with contributor equity as the project grows.

---

## What we are building

**Connectome** is a multi-agent AI system where:
- Ora (the brain) generates personalized JSON screen specs in real-time
- A React Native mobile app renders those specs dynamically
- Every user interaction feeds back to update user embeddings
- The AI learns, adapts, and continuously improves

**Stack:** FastAPI · PostgreSQL + pgvector · Redis · Expo React Native

**Codebase:** `/connectome/backend` (Python) + `/connectome/mobile` (TypeScript/React Native)

## Areas of contribution

### AI / Agent Systems
- Improve agent quality and reasoning
- Add new specialized agents
- Improve the orchestration logic in `brain.py`
- Deepen feedback loop intelligence

### Backend / Infrastructure
- FastAPI endpoints
- Database schema and migrations
- Redis caching and optimization
- API performance

### Mobile / Frontend
- Expo React Native components
- Screen renderer improvements
- UX and interaction design
- Onboarding flow

### Product / Research
- User research and feedback synthesis
- Architecture proposals
- Documentation
- Content and knowledge systems

## Principles

- **Fulfilment over engagement** — we optimize for what's genuinely good for users
- **Clarity over mystique** — code and decisions should be understandable
- **Practical value over vanity** — build things that work and matter
- **Open collaboration** — no gatekeeping, credit given openly
